As a member of the **Kapsül Tulpar electric vehicle team**, I work on the technical side of the vehicle, particularly:

- 🔧 Vehicle Control System (AKS)
- 📡 Telemetry infrastructure
- 🔌 CAN / RS485 communication
- 🍓 Raspberry Pi based systems
